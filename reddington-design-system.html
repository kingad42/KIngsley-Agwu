Reddington Hospital — turning a confusing site into a trusted booking experience

A healthcare website redesign for a leading private hospital in Lagos, Nigeria — built around patient booking, a symptom checker, and mobile-first trust signals. This page breaks down the actual design system used to build it.

Category
UI/UX Design · Development
Fonts
Playfair Display + DM Sans
Tools
Figma · HTML/CSS · User Research
Overview

From "which doctor do I even need?" to a booked appointment

The Problem

Patients struggled to find the right specialist, navigate services, and book appointments online. The existing digital presence lacked structure, trust signals, and mobile responsiveness.

The Solution

A clean, professional site anchored by a full-bleed hero, a symptom checker, a streamlined booking form, and a specialization directory — all in a warm red-and-blue palette suited to healthcare rather than tech.

Key Features

Appointment booking form · Symptom checker tool · Specializations directory · Trust stats bar · Fully responsive layout.
